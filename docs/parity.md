## 来源覆盖与限制

Mimestream 基准来源均来自 mimestream.com；本次实际打开正文，不依据搜索摘要。用户指南索引的 54 个入口全部已读，包括 Keyboard Shortcuts、安装与激活、账号／Profile、侧栏／标签、列表、阅读、撰写及设置。发布记录完整读取至早期 0.2.x，提取新增功能并与现行指南交叉核验；修复条目仅用于证实仍有相应产品路径，不把每条修复重复算作功能。已补读 1.0、1.2、1.3、1.5、1.9、1.10 发布博客与 2026 年系统要求／iOS beta 公告。

官方文档有时间冲突：Private Push 在旧 1.9 说明中是 Labs，1.10/macOS 26 已默认启用；缓存管理在 1.9 中间版本曾改为 opt-in，1.10.5 再默认启用；声音设置以 1.10 发布记录移交系统设置为准，不要求照旧 General 指南重建通知声音选择器。用户指南会话展开键与快捷键表不同，清单审计功能，不据冲突文档硬编码键位。

限制：未登录 Mimestream 的订阅账号或 TestFlight，未验证私有 beta 与隐藏实验选项；公开路线图重定向到 Productboard 且无可读正文，因此不把路线图卡片当作已发货功能。未执行 Mimestream app 的 UI 实测，原生能力与版本行为来自一手文档。官网未证明的计划发送和 read receipt 不擅自补入；Filters 的编辑能力由手册和 1.5 发布修复确认，但仍需实测才能定义全部 UI 细节。
