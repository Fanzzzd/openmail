# 图标候选

`contact-sheet.png` 把每个方案按 256、128、32、16 px 排在浅色和深色背景上。最右两格是 32 和 16 px 的渲染放大到 64 px，方便看像素。

重新生成：`python3 docs/design/icon-options/build.py`。脚本从 `apps/desktop/build/icon.svg` 读 squircle 路径，只写本目录。

## 方案

**01 Open flap。** 信封的封口向上打开，露出黄色内衬。外轮廓像一座房子，同时对应 "open" 和"邮件在你自己的机器上"。16 px 还能看出黄三角加白块。

**02 Wax seal。** 信封背面用红色火漆封口，火漆上压一个 "o"。火漆代表人工确认：agent 可以起草，封口和发送由你来做。16 px 缩成白底红点，Dock 里没有别的邮件 app 长这样。

**03 Spaces。** 几张不同颜色的卡片扇形叠在一起，最上面是信封。每张卡片是一个 space。32 px 能看出彩色层次，16 px 只剩一个白色信封。

**04 o envelope。** 小写 "o" 拉宽成信封外框，中间一道蓝色封口线。靠字形取胜，单色也能用，适合托盘图标和网页 favicon。16 px 是黑色圆角框加一点蓝，轮廓清楚，但信封的意思会变弱。

**05 Pigeonholes。** 邮局分拣柜，四个格子里三个放着信。每个格子是一个账户，信放在你自己的柜子里。16 px 是橙底深色田字格，辨识度高，但看不出是邮件。

**06 Local store。** 数据库圆柱，顶盖上画一道信封封口线。直接说明本地 SQLite。16 px 圆柱轮廓保得住。缺点是开发者味重，普通用户会以为是数据库工具。

**07 Proposal。** 后面是虚线框的草稿，前面是实心信封。虚线是 agent 的提议，实心是你批准后的信。16 px 虚线糊成浅色边，只剩信封能读出来。

去掉的方案：08 Letter slot，门上的投信口加一封信。缩小后像打印机出纸，已删除。

## 推荐

02 Wax seal。它在 16 px 下还是一个白底红点，和 Apple Mail、Airmail 的蓝色信封拉得最开，火漆本身又对应"人来确认"这条产品原则。
